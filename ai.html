What is Obelisk & Why It Solves Modern Proof Gridlock

Curry–Howard for Impredicative Classes

🌌 First-Class Proper Classes

In standard ZFC and dependent type systems (Lean 4, Coq), collections like the universal class \(V\) or the category of all sets \(\mathbf{Set}\) cannot be manipulated as ordinary elements without triggering Russell's paradox or ascending into infinite universe hierarchies (Type u). Obelisk adopts Morse–Kelley (MK) class theory: proper classes are native first-class objects with full impredicative comprehension over classes.

🏷️ Dunaev Tagged Ordered Pairs

Standard Kuratowski pairs \(\langle A, B \rangle = \{\{A\}, \{A, B\}\}\) fail for proper classes because proper classes cannot be elements of sets. Obelisk solves this via Dunaev Tagged Pairs \(\langle \text{tag}, A, B \rangle_{\text{tag}}\), allowing proper classes and infinite families to form pairs and lists with zero set-theoretic rank inflation and full algebraic projection invertibility.

⚖️ Zero Implicit Computation

Type-theoretic proof assistants suffer from fragile computational reduction (\(\beta\delta\iota\)): definition updates break proof scripts invisibly. Obelisk separates syntax from semantics through the explicit valuation bracket \(\llbracket \cdot \rrbracket\). Every deduction is a checkable syntactic tree; inference rules have explicit side conditions with no hidden normalization noise.

Compiler Architecture · Standard ML & CakeML

        
Morse-Kelley Propositions-as-Types: Compiling to Check, Not Execute

      


      

        

          In Obelisk, we establish a strict 1-to-1 Curry–Howard correspondence between mathematical theorems of Morse-Kelley (MK) Impredicative Class Theory and compiler types.
          Because MK allows quantification over proper classes in class comprehension, it provides the full expressive strength of higher-order logic over sets, while the compiler operates under the foundational principle: it compiles not to generate runtime executable bytecode, but strictly to verify whether the proof expression type-checks.
        


        

          

            
Standard ML Native Kernel

            

              Eliminates dynamically typed languages like Python from the trusted kernel. Fully written in Standard ML 97 targeting the CakeML verified compiler for machine-code assurance down to silicon.
            

          

          

            
Theorems as Types (1-to-1)

            

              Every mathematical theorem (Modus Ponens, Conjunction Symmetry, Russell Paradox Refutation) corresponds to a unique type. Proof terms are formal witnesses checked by the SML type checker.
            

          

          

            
Dunaev Tagged Ordered Pairs

            

              Replaces Kuratowski pairs (which inflate rank by +2) with tagged tuples <tag, x, y> that preserve set-theoretic rank, well-foundedness, and algebraic projections without universe elevation.
