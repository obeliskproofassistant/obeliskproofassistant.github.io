Foundations Book Formalization (`110_family_evaluation.tex` & `130_classes_as_types.tex`)

In Morse–Kelley / NBG class theory, dependent type constructors \( \Sigma_{x \in A} B(x) \) and \( \Pi_{x \in A} B(x) \) are modeled via class families encoded by Dunaev tagged ordered pairs \( [x, y]_D \) and evaluated via semi-singleton subclass extraction:

  • Semi-Singleton Predicate (3.67 semi_singleton): \( (\mathrm{semi\_singleton}(x) \longleftrightarrow \forall u\; \forall v\; (((u \in x) \land (v \in x)) \to (u = v))) \).
  • Value Operator & Set-Domain Restriction (3.68 sss / Value): \( (\mathrm{sss}(x) = \bigcup \{ z \mid ((z \subseteq x) \land \mathrm{semi\_singleton}(z)) \}) \). Crucially, \( (\mathrm{sss}(\{a\}) = a) \) holds only when \( a \) is a set (\( a \in V \), i.e. \( \mathrm{isSet}(a) \)). If \( X \) is a proper class (\( \neg \mathrm{isSet}(X) \)), then \( \{X\} = \emptyset \) in MK/NBG because proper classes cannot be elements of any class, so \( (\mathrm{sss}(\{X\}) = \mathrm{sss}(\emptyset) = \emptyset) \) rather than \( X \).
  • Family Evaluation Theorem (3.69 family_eval_thm): For an encoded family \( (\Lambda x,\, t) = \{ [x, y]_D \mid (y \in t) \} \) with fiber \( B(z) = \{ y \mid ([z, y]_D \in B) \} \), evaluating at a set \( z \in V \) yields \( (((\Lambda x,\, t))(z) = t[z/x]) \).
  • Dependent Sum Model (3.70 ΣB): \( (\Sigma B = \{ p \mid \exists x\; \exists y\; (((x \in \mathrm{Dom}(B)) \land (y \in B(x))) \land (p = [x, y]_D)) \}) \).
  • Dependent Product Model (3.71 ΠB): \( (\Pi B = \{ f \mid ((\mathrm{isClassFunction}(f) \land (\mathrm{Dom}(f) = \mathrm{Dom}(B))) \land \forall x\; ((x \in \mathrm{Dom}(B)) \to (f(x) \in B(x)))) \}) \).
