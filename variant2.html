Variant 2 — Semantical Proof Assistant (`variants/variant2_higher_order/`, Formulas-as-Types / Curry–Howard)
Curry–Howard propositions-as-types / dependent-type architecture (nbg_compiler.ML, nbg_surface_compiler.ML, dependent_eval.ML) where propositions/formulas are types directly (Theorem name : φ, prf : φ), implications are function spaces, quantifiers are dependent products/sums, and proofs are constructive λ-terms—without needing ProofOf or quotation brackets ⟨...⟩.
Semantic Function Class & Curry–Howard Arrow (→): In Variant 2, (A → B) is the semantic class of functions from class/set A to class/set B (special case of Π_{x ∈ A} B), and under Curry–Howard propositions-as-types, a proof of (φ → ψ) is a constructive λ-abstraction mapping proofs of φ to proofs of ψ (see dual meaning of →).
Note on cantor_diagonal_theorem (#12): ∀(S : Class) ∀(F : Class) ∀(D : Class) ((∀(z : Class) ((z ∈ D) ⟷ ((z ∈ S) ∧ ¬([z, z]_D ∈ F)))) → ¬∃(x : Class) ((x ∈ S) ∧ ∀(z : Class) ((z ∈ D) ⟷ ([x, z]_D ∈ F)))) formalizes Cantor's diagonal theorem over arbitrary indexed families F of subclasses of S encoded via Dunaev tagged pairs [x, z]_D: no index x ∈ S can have Cantor's anti-diagonal class D = { z ∈ S ∣ ¬([z, z]_D ∈ F) } as its fiber F(x).
