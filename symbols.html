Two Switchable Notation Options: Standard (“:”) vs. Non-Ambiguous (“::”)

Every symbol, operator, connective, quantifier, bracket, and sort across the Obelisk Proof Assistant is clickable in formulas (both MathJax LaTeX and Colorful Unicode) and in the Symbols: bar under each statement. Use the Notation Option switch above to choose between:

  • Beautiful, Standard (Potentially Ambiguous): Uses single colon : for symbol typing signatures — e.g. (isSet: (Class → Bool)), (V: Class), (⊆: (Class × Class → Bool)) — and standard textbook parenthesization where outer parentheses around formulas and quantifiers are omitted.
  • Non-Ambiguous (Default): Uses double colon :: for metalevel symbol-signature typing so it is never confused with object-level typing (x : Class), wraps operator symbols in parentheses ((⊆) :: ((Class × Class) → Bool)), and retains explicit parentheses around all binary infix operators and quantified formulas.
