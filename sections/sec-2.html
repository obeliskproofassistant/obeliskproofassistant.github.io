2.01 Axiom Discourse domain is non-empty
Symbol Signature: (∀: ((Class → Bool) → Bool))((∀) :: ((Class → Bool) → Bool))
▸ Note
Layered axiomatization: Section 2 axiomatizes pure First-Order Predicate Logic over sort Class prior to Section 3 (Class Comprehension). In multi-sorted / inclusive predicate logic (where some sorts like Nonstored / Void are uninhabited), 2.01 explicitly postulates that the sort Class is inhabited so (∀(K : Class) φ) → (∃(K : Class) φ) holds in pure predicate logic; once Section 3's Class Comprehension Axiom (3.01) is added, 2.01 becomes derivable (witnessed by ∅).
