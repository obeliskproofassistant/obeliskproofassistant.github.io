2.02 Inference Rule Forall Instantiation (FI)
comment
Term t is free for substitution for variable identifier v_x in formula φ.
\(((\forall (x : \mathsf{Class})\; \phi) \to \phi[t/x])\)
\(((\forall x \; \phi) \to \phi[t/x])\)
 \(\mathrm{FFI}(t, \mathbf{v}_x, \phi) : \mathsf{Bool}\)\(\mathrm{FFI}(t, \mathbf{v}_x, \phi) : \mathsf{Bool}\) Primitive Rule
2.03 Inference Rule Exists Instantiation (EI)
comment
Witness substitution into existential quantifier.
\((\phi[t/x] \to \exists (x : \mathsf{Class})\; \phi)\)
\((\phi[t/x] \to \exists x \; \phi)\)
 \(\mathrm{FFI}(t, \mathbf{v}_x, \phi) : \mathsf{Bool}\)\(\mathrm{FFI}(t, \mathbf{v}_x, \phi) : \mathsf{Bool}\) Primitive Rule
2.04 Inference Rule Forall Abstraction (FA / Bernays)
comment
Eigenvariable condition: variable identifier v_x does not occur free in antecedent ψ or context Γ.
\(\frac{(\psi \to \phi)}{(\psi \to \forall (x : \mathsf{Class})\; \phi)}\)
\(\frac{(\psi \to \phi)}{(\psi \to \forall x \; \phi)}\)
 \((\mathrm{NFV}(\mathbf{v}_x, \psi) : \mathsf{Bool} \land \mathrm{NFV}(\mathbf{v}_x, \Gamma) : \mathsf{Bool})\)\((\mathrm{NFV}(\mathbf{v}_x, \psi) : \mathsf{Bool} \land \mathrm{NFV}(\mathbf{v}_x, \Gamma) : \mathsf{Bool})\) Primitive Rule
2.05 Inference Rule Exists Abstraction (EA / Bernays)
comment
Dual eigenvariable condition: v_x not free in consequent ψ or assumptions.
\(\frac{(\phi \to \psi)}{\exists (x : \mathsf{Class})\; (\phi \to \psi)}\)
\(\frac{(\phi \to \psi)}{\exists x \; (\phi \to \psi)}\)
 \((\mathrm{NFV}(\mathbf{v}_x, \psi) : \mathsf{Bool} \land \mathrm{NFV}(\mathbf{v}_x, \Gamma) : \mathsf{Bool})\)\((\mathrm{NFV}(\mathbf{v}_x, \psi) : \mathsf{Bool} \land \mathrm{NFV}(\mathbf{v}_x, \Gamma) : \mathsf{Bool})\) Primitive Rule
2.06 Inference Rule Generalisation (Gen)
comment
Universal generalization over variable identifier v_x not free in active context Γ.
\(\frac{\phi}{\forall (x : \mathsf{Class})\; \phi}\)
\(\frac{\phi}{\forall x \; \phi}\)
 \(\mathrm{NFV}(\mathbf{v}_x, \Gamma) : \mathsf{Bool}\)\(\mathrm{NFV}(\mathbf{v}_x, \Gamma) : \mathsf{Bool}\) Primitive Rule
