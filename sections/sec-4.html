4.09 Definition Syntactic Encoding Operator (Enc)
comment
Gödel / Hereditarily-Finite-Set encoding (CpEnc in typetheory.ML). Maps any finite syntactic object s : T (Fm, Ctx, Theory, Stmt, Prf) into a finite set code in V_ω ⊂ V, so isSet(Enc(s)) is always true.

4.12 Definition Proof-Object Class Family (ProofsOf)

Maps an encoded statement Enc(s) (or formula Enc(φ)) to the class of all encoded verified proof objects witnessing it: ProofsOf : Fm → 𝒫(Proofs). Reconciles Variant 2 typing (p : ProofsOf(φ)) with Variant 1 membership (Enc(p) ∈ ProofsOf(Enc(s))).
