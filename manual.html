1. Core Foundations: Morse–Kelley Class Theory

The Obelisk kernel formalizes an impredicative class theory where the universe of discourse consists of classes. A class is defined to be a set if and only if it is an element of some other class:

isSet(X) ⇔ ∃ Y. X ∈ Y def isSet (X : Class) : Prop := ∃ Y : Class, X ∈ Y
Definition 3.02 (Sethood Criterion) · Class variable $X$
📐 Foundational Decoupling: "x" as a Semantic Set vs. "vx" as a Syntactic Variable

A crucial distinction in Obelisk (cf. Vereshchagin & Shen, Languages and Calculi, Part 2, Ch. 4; Obelisk program/types/typetheory.ML and program/types/foundations.ML) is the decoupling of the semantic level from the syntactic level:

  • The Semantic Column (Object Theory): Here, \(x\) is a mathematical entity (a set or class) inhabiting the domain of discourse: \(x \in Y\), \(A \subseteq B\), \(\mathrm{isSet}(x)\). Any condition regarding meaning (such as \(\mathrm{isSet}(B)\), non-emptiness \(X \ne \emptyset\), or injectivity \(\mathrm{Inj}(f)\)) is formulated directly within the formula of the statement itself (as an antecedent \(P \to Q\), bounded quantifier, or conjunct).
  • The Syntax Column (Ambient Syntactic Type Theory): Here, \(v_x\) is a variable identifier constant (type \(v_x : \mathsf{Variable}\)), belonging to the syntactic AST alongside terms (\(t : \mathsf{Term}\)) and formulas (\(\phi : \mathsf{Fm}\)). Side conditions are not informal prose: they are formulas themselves within an ambient type theory (e.g. \(\mathsf{FFI}(t, v_x, \phi) : \mathsf{Bool}\) for freedom of substitution, \(\mathsf{NFV}(v_x, \psi) : \mathsf{Bool}\) for not-free-variable checks). Click any side condition to inspect its semantic formula in the Metatheory Engine.
  • Statement Schemata vs. Theorem Schemata: Do not mix statement schemata and theorem schemata! A statement schema is a family of formula types indexed by metavariables without asserting a proof program. A theorem schema implies that there exists an explicit program (proof term) inhabiting that type for every valid instance.
  • Only One Atomic Type (Class) & Ordinal Induction: The class of ordinals \(\mathrm{On}\) is not a type (it is not syntactic); it is a Class object (\(\mathrm{On} \in \mathsf{Class}\)). In Obelisk, there is only one atomic base object type, called Class, on top of which a dependent type theory is given. Therefore, Ordinal Induction (∈-Ind) is a Theorem Schema over Class with an explicit proof program; the restriction \(\alpha \in \mathrm{On}\) is an internal antecedent in the semantic formula, not a syntactic type.

2.1 Core Inference Rules: Semantic Schemata & Syntactic Side Conditions

In the Obelisk LCF kernel (cf. Vereshchagin & Shen, Languages and Calculi, Part 2, Ch. 4; Obelisk program/types/foundations.ML and program/newchecker.ML), inference rules transform semantic formulas under the guard of syntactic side-condition formulas in the ambient type theory:

Inference Rule Semantic Derivation Schema Syntax (Type-Theoretic Side Condition) Action
Modus Ponens (MP)
Γ ⊢ A → B     Δ ⊢ A  ⟹  Γ ∪ Δ ⊢ B
val MP : thm -> thm -> thm
 None (Type: A, B : Fm; unconditional propositional rule)
∀-Instantiation (FI / Axm 12)
⊢ (∀ x. φ) → φ[t/x]     (Γ ⊢ ∀ x. φ  ⟹  Γ ⊢ φ[t/x])
val rule_FI : term -> variable -> thm -> thm (* foundations.ML: sidconFFI *)
Semantic note: x is an object variable instantiated with term t
FFI(t, v_x, φ) : Bool ↗
Term t : Term is free for substitution for variable identifier v_x : Var in formula φ : Fm (sidconFFI; no quantifier capture)
∃-Instantiation (EI / Axm 13)
⊢ φ[t/x] → ∃ x. φ     (Γ ⊢ φ[t/x]  ⟹  Γ ⊢ ∃ x. φ)
val rule_EI : term -> variable -> thm -> thm (* foundations.ML: sidconFFI *)
Semantic note: x is an object variable witnessed by term t
FFI(t, v_x, φ) : Bool ↗
Term t : Term is free for variable identifier v_x : Var in formula φ : Fm (sidconFFI)
∀-Abstraction (FA / ∀I)
Γ ⊢ ψ → φ  ⟹  Γ ⊢ ψ → ∀ x. φ     (Γ ⊢ φ  ⟹  Γ ⊢ ∀ x. φ)
val rule_FA : variable -> thm -> thm (* foundations.ML: sidconNFV *)
Semantic note: universal generalization over class variable x
NFV(v_x, ψ) : Bool  |  NFV(v_x, Γ) : Bool ↗
Eigenvariable condition: variable identifier v_x : Var does not occur free in antecedent ψ : Fm or context Γ : Ctx (sidconNFV)
∃-Abstraction (EA / ∃E)
Γ ⊢ φ → ψ  ⟹  Γ ⊢ (∃ x. φ) → ψ     (Γ ⊢ ∃ x. φ, Δ, φ[y/x] ⊢ ψ  ⟹  Γ ∪ Δ ⊢ ψ)
val rule_EA : variable -> thm -> thm (* foundations.ML: sidconNFV *)
NFV(v_x, ψ) : Bool  |  NFV(v_y, Δ ∪ {∃ x. φ, ψ}) : Bool ↗
Eigenvariable condition: variable identifier v_x : Var (resp. fresh v_y : Var) does not occur free in consequent ψ : Fm or hypotheses (sidconNFV)
Generalisation (Gen)
⊢ φ  ⟹  ⊢ ∀ x. φ
val rule_Gen : variable -> thm -> thm (* Generalisation_rul *)
NFV(v_x, Γ) : Bool ↗
Variable identifier v_x : Var is not free in any active undischarged assumption in context Γ
Substitution (Leibniz)
Γ ⊢ s = t     Δ ⊢ φ[s/x]  ⟹  Γ ∪ Δ ⊢ φ[t/x]
val rule_subst : thm -> thm -> thm
FFI(s, v_x, φ) ∧ FFI(t, v_x, φ) : Bool ↗
Terms s, t : Term are free for variable identifier v_x : Var in formula φ : Fm (no variable capture)
Class Comprehension (CCR)
⊢ y ∈ {x | φ(x)} ⇔ isSet(y) ∧ φ[y/x]
val ComprAx : (Truth.Expression LBound) -> Thm (* newchecker: ComprAx *)
Semantic note: x, y are class/set variables in comprehension
FFI(v_y, v_x, φ) ∧ NFV(v_y, {v_x | φ}) : Bool ↗
Variable identifier v_y : Var is free for bound variable identifier v_x : Var in φ : Fm and does not clash with the binder

3. The Machine-Checked Lean 4 Verification (Core Showcased Theorems)

Core theorems from the Obelisk demonstration formalized and machine-checked in Lean 4 without Mathlib dependencies. Source file: Obelisk.lean.

In Morse–Kelley class theory, all theorems are proven statements in the object language. All mathematical prerequisites (such as sethood or element membership) are internal antecedents within the semantic formula, not external side conditions. Closed theorems have no syntactic side conditions.

Thm 1: empty_unique
Semantic Formula: ∀ E1 E2. ∅(E1) ∧ ∅(E2) ⇒ E1 = E2
theorem empty_unique (E1 E2 : Class) : E1 = E2
Semantic Hypotheses (in formula): ∀ x. ¬(x ∈ E1) and ∀ x. ¬(x ∈ E2)
Syntax (Type-Theoretic Side Condition): None (Closed theorem; element non-membership is internal to formula)
Thm 2: extensionality
Semantic Formula: X = Y ⇔ ∀ z. (z ∈ X ⇔ z ∈ Y)
theorem extensionality (X Y : Class) : X = Y
Semantic Hypothesis (in formula): ∀ z. (z ∈ X ⇔ z ∈ Y) (antecedent in implication)
Syntax (Type-Theoretic Side Condition): None (Closed theorem; element equivalence is an internal antecedent)
Thm 3: hereditary_subsets
Semantic Formula: A ⊆ B ∧ isSet(B) ⇒ isSet(A)
theorem hereditary_subsets (A B : Class) : isSet A
Semantic Hypotheses (in formula): A ⊆ B and isSet(B) (explicit antecedents in implication)
Syntax (Type-Theoretic Side Condition): None (Closed theorem; sethood of B is part of the formula, not an external proviso)
Thm 5: not_isSet_V (Russell)
Semantic Formula: ¬ isSet(V) (Resolves Russell Paradox)
theorem not_isSet_V : ¬ isSet V
Semantic Hypotheses (in formula): None (unconditional negation theorem)
Syntax (Type-Theoretic Side Condition): None (Closed theorem)
Thm 7: on_not_set (Burali-Forti)
Semantic Formula: ¬ isSet(On) (Resolves Burali-Forti Paradox)
theorem on_not_set : ¬ isSet On
Semantic Hypotheses (in formula): None (unconditional negation theorem)
Syntax (Type-Theoretic Side Condition): None (Closed theorem)
Thm 9: tagged_pair_proj
Semantic Formula: π1(⟨A, B⟩) = A ∧ π2(⟨A, B⟩) = B
theorem tagged_pair_proj (A B : Class) : proj1 (tagged_pair A B) = A ∧ proj2 (tagged_pair A B) = B
Semantic Hypotheses (in formula): None (holds universally for all classes A, B)
Syntax (Type-Theoretic Side Condition): None (Closed theorem; holds unconditionally)
