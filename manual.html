1. Core Foundations: Morse–Kelley Class Theory

The Obelisk kernel formalizes an impredicative class theory where the universe of discourse consists of classes. A class is defined to be a set if and only if it is an element of some other class:

isSet(X) ⇔ ∃ Y. X ∈ Y def isSet (X : Class) : Prop := ∃ Y : Class, X ∈ Y
Definition 3.02 (Sethood Criterion) · Class variable $X$

2.1 Core Inference Rules & Explicit Side Conditions

In LCF-style proof assistants, sound logical derivation depends strictly on validating all side conditions (such as variable freeness and eigenvariable freshness) before firing an inference rule:

Inference Rule Formal Derivation Schema Explicit Side Conditions (Required Checks) Action
Modus Ponens (MP)
Γ ⊢ A → B     Δ ⊢ A  ⟹  Γ ∪ Δ ⊢ B
val rule_mp : thm -> thm -> thm
 None (Unconditional propositional elimination)
∀-Introduction (∀I)
Γ ⊢ φ(x)  ⟹  Γ ⊢ ∀ x. φ(x)
val rule_forall_intro : string -> thm -> thm
x ∉ FV(Γ)
Eigenvariable condition: variable x must NOT occur free in any active hypothesis in Γ
∃-Elimination (∃E)
Γ ⊢ ∃ x. φ(x)     Δ, φ(y) ⊢ ψ  ⟹  Γ ∪ Δ ⊢ ψ
val rule_exists_elim : thm -> string -> thm -> thm
y ∉ FV(Δ ∪ {∃ x. φ(x), ψ})
Fresh witness parameter y cannot occur free in hypotheses or conclusion
Substitution (Leibniz)
Γ ⊢ s = t     Δ ⊢ φ[s/x]  ⟹  Γ ∪ Δ ⊢ φ[t/x]
val rule_subst : thm -> thm -> thm
s, t free for x in φ
No free variables in terms s or t become bound after substitution
Ord Induction (∈-Ind)
(∀ α ∈ On. (∀ β < α. P(β)) ⇒ P(α))  ⟹  ∀ α ∈ On. P(α)
theorem ordinal_induction (P : Class -> Prop) : (∀ a, is_ord a -> (∀ b, b ∈ a -> P b) -> P a) -> (∀ a, is_ord a -> P a)
α, β ∈ On
Restricted strictly to the well-ordered class of ordinals On

3. The Machine-Checked Lean 4 Verification (9 Core Theorems)

All 9 core theorems from the Obelisk demonstration were formalized in Lean 4 without Mathlib dependencies. Source file: Obelisk.lean.

Thm 1: empty_unique
Uniqueness of the empty class: ∀ E1 E2. ∅(E1) ∧ ∅(E2) ⇒ E1 = E2
theorem empty_unique (E1 E2 : Class) : E1 = E2
Side Condition: None (Unconditional theorem)
Thm 2: extensionality
Extensionality of classes: X = Y ⇔ ∀ z. (z ∈ X ⇔ z ∈ Y)
theorem extensionality (X Y : Class) : X = Y
Side Condition: Classes X and Y share identical element membership
Thm 3: hereditary_subsets
Subclasses of sets are sets: A ⊆ B ∧ isSet(B) ⇒ isSet(A)
theorem hereditary_subsets (A B : Class) : isSet A
Side Condition: isSet(B) required as hypothesis
Thm 5: not_isSet_V (Russell)
Universal Class is Proper: ¬ isSet(V) (Resolves Russell Paradox)
theorem not_isSet_V : ¬ isSet V
Side Condition: Universal class definition V := {x | isSet(x)}
Thm 7: on_not_set (Burali-Forti)
Ordinal Class is Proper: ¬ isSet(On) (Resolves Burali-Forti Paradox)
theorem on_not_set : ¬ isSet On
Side Condition: On := {a | is_ord(a)} under transfinite induction
Thm 9: tagged_pair_proj
Tagged pair invertibility: π1(⟨A, B⟩) = A ∧ π2(⟨A, B⟩) = B
theorem tagged_pair_proj (A B : Class) : proj1 (tagged_pair A B) = A ∧ proj2 (tagged_pair A B) = B
Side Condition: Valid for all classes A, B (sets or proper classes)
