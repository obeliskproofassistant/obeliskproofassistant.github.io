Mathematical Architecture: Semantic Formulas vs. Syntactic Side Conditions

In the Obelisk Proof Assistant, the classical confusion between mathematical set-theoretic semantics and syntactic metalevel manipulation is formally and rigorously decoupled:

  • Semantic Column (Morse–Kelley Object Theory): Formulates statements about mathematical objects. The discourse domain consists solely of the atomic type \(\mathsf{Class}\\). Mathematical sets are classes satisfying \(\mathrm{isSet}(x) \equiv \exists(y : \mathsf{Class})(x \in y)\\). Any condition regarding meaning belongs entirely within the formula itself.
  • Syntax Column (Ambient Type Theory): Formulates statements about the language expressions themselves (variable freeness, substitution safety, context hygiene). Side conditions are not arbitrary informal comments—they are checkable formulas in an ambient type theory (such as \(\mathrm{NFV}(v_C, \phi) : \mathsf{Bool}\) or \(\mathrm{FFI}(t, v_x, \phi) : \mathsf{Bool}\)).
  • Syntactic Constants: When a variable \(x\) is referenced inside a side condition, it reifies as a constant identifier \(v_x : \mathsf{Variable}\) in the metatheory. The metatheory is the same Morse–Kelley theory functioning as a meta-language. Click any side condition to navigate to its reflected form in the Metatheory Specification.
  • Theorem Schemata vs. Statement Schemata: A statement schema is a collection of propositions. A Theorem Schema (such as Ordinal Induction, 3.32) guarantees the existence of a machine-checked proof program term inhabiting the schema type.

Predicative/impredicative comprehension for all first-order and higher-order formulas.

3.02 Axiom Extensionality Axiom
Two classes having identical elements are identical.
 \\(\forall (A, B : \mathsf{Class})\; ((\forall (x : \mathsf{Class})\; (x \in A \longleftrightarrow x \in B)) \to A = B)\\) \\(A, B, x : \mathsf{Class}\\) Verified

Any subclass of a set is a set.
 \\(\forall (A, B : \mathsf{Class})\; ((\mathrm{isSet}(B) \land A \subseteq B) \to \mathrm{isSet}(A))\\) \\(A, B : \mathsf{Class}\\) Verified
3.12 Axiom Regularity (Foundation) Axiom
Every non-empty class contains an ∈-minimal element. Rules out infinite descending ∈-chains.
 \\(\forall (A : \mathsf{Class})\; (A \ne \emptyset \to \exists (x : \mathsf{Class})\; (x \in A \land x \cap A = \emptyset))\\) \\(A, x : \mathsf{Class}\\) Verified
3.13 Axiom Pairing Axiom
Unordered pair of two sets is a set.
 \\(\forall (a, b : \mathsf{Class})\; ((\mathrm{isSet}(a) \land \mathrm{isSet}(b)) \to \mathrm{isSet}(\{a, b\}))\\) \\(a, b : \mathsf{Class}\\) Verified
3.14 Axiom Union Axiom
The unary union of any set is a set.
 \\(\forall (A : \mathsf{Class})\; (\mathrm{isSet}(A) \to \mathrm{isSet}(\bigcup A))\\) \\(A : \mathsf{Class}\\) Verified
