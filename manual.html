1. Core Foundations: Morse–Kelley Class Theory

The Obelisk kernel formalizes an impredicative class theory where the universe of discourse consists of classes. A class is defined to be a set if and only if it is an element of some other class:

isSet(X) ⇔ ∃ Y. X ∈ Y (Definition 3.02)

3. The Machine-Checked Lean 4 Verification

All 9 core theorems from the Obelisk demonstration were formalized in Lean 4 without Mathlib dependencies. The full source code is available in Obelisk.lean:

  • Theorem 1: Uniqueness of the empty set (empty_unique)
  • Theorem 2: Extensionality of classes (extensionality)
  • Theorem 3: Subclasses of sets are sets (hereditary_subsets)
  • Theorem 4: Epsilon-transitivity of ordinals (transitivity_in)
  • Theorem 5: Russell's Paradox resolution: Universe V is not a set (not_isSet_V)
  • Theorem 6: Transfinite induction on ordinals (ordinal_induction)
  • Theorem 7: Burali-Forti Paradox resolution: On is a proper class (on_not_set)
  • Theorem 8: Kuratowski pair set-property (kuratowski_pair_set)
  • Theorem 9: Dunaev tagged pair projection theorem (tagged_pair_proj)
