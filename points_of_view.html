Declaration of Principles & The Seven Mathematical Points of View

How MKTD1-system and MKTD2-system untangle distinct views on types, classes, syntax, and metatheory—and model all of them within a single foundational system without contradiction.

“In mathematics, good principles are those which simplify things, but do not oversimplify (so they do not make the system contradictory). Loosely speaking, everything has a certain type, depending on how we look at it—different type systems, levels, or languages—and what is remarkable about mathematics is that all of those systems can and should be modelled within the very system we are developing.”

1. The Seven Mathematical Points of View on “What Is What”

When we write a typing or classification judgement in formal mathematics, its meaning depends on our active point of view. Rather than conflating these views, the Obelisk kernel untangles them into seven explicit perspectives and proves how they model one another:

View 1 • Metalevel 0 Ontology

Pure Class Ontology (MKTD1-theory)

Every object in the domain of discourse is a Class. Sets are not a separate syntactic sort; a set is a class that is an element of some class ($\mathrm{Set}(X) \iff \exists Y.\, X \in Y \iff X \in V$, #DefIsSet). Proper classes ($V, \mathrm{On}$) are non-elements (#DefIsProperClass). Using Dunaev Tagged Ordered Pairs $(A, B) = \mathrm{mark}(A, 0) \cup \mathrm{mark}(B, 1)$ (#DefDunaevOrderedPair), pairing, projections, and families work uniformly across all classes (#ThmDunaevOpairInjective).

View 2 • Conglomerates as Types

Predicates on Classes (Huge_Col)

A “type” of classes $T$ is a Conglomerate—a unary predicate on classes $T : \mathrm{Class} \to \mathrm{Bool}$ (LPredicate in typetheory.ML). The default sort Class (TClass) is the universal predicate $\lambda X.\,\top$. A typed quantifier $\forall(x : A)\varphi(x)$ is canonically guarded by the conglomerate predicate $A(x)$.

View 3 • Internal Type Models

Set-Theoretic Models of Dependent Types

Dependent type theory is modeled inside MKTD1-theory via indexed class-families (#DefIsFamily): Dependent Sum $\Sigma(B)$ (#DefSigmaModel), Dependent Product $\Pi(B)$ (#DefPiPredicateModel), Natural Numbers $\omega$ (#DefFiniteOrdinalsOmega), cumulative stages $V_\alpha$ via #DefTransfiniteRecursionOperator, and Grothendieck-Tarski Universes satisfying $U = V_{U \cap \mathrm{On}}$ (#ThmUniverseEqVonNeumannStageInterOn).

View 4 • Curry-Howard Constructivism

Propositions-as-Types (MKTD2-theory)

In MKTD2-system (225 constructive theorems), formulas are types (Fm : Type) and proofs are $\lambda$-terms (p : A). Universal quantification and implication are unified as $\Pi(x : A), B(x)$; existential quantification and conjunction are unified as $\Sigma(x : A), B(x)$; false formulas are uninhabited types ($\simeq \mathbb{0}$). Connected to View 1 & View 3 via program/variant_bridge.ML.

View 5 • Metalevel 1 & 2 Functor Tower

SML Off-by-One AST Hierarchy (typetheory.ML)

Semantic Class is Nonstored.t in SML (Fact 1: a class never sits in RAM and cannot be free or bound). SML stores syntactic levels built by the MAKE functor: Pattern (Class_p / Truth_p) $\hookrightarrow$ Half-Expression (.Expre) $\hookrightarrow$ Level-1 Expression (.Expression) $\hookrightarrow$ Level-2 Reflected Term (.Expression.Expression).

View 6 • Combinatorial Syntax

Wire-and-Box Graphs (Vereschagin & Shen)

Following Vereschagin & Shen, bound variable names are temporary coordinates for wires linking a binder hub (VarPos_Binder) to bound occurrences (BoundVarOccurrence). Erasing bound names yields a canonical WireBoxSchema (ai_playground/symbol_ontology.ML) where $\alpha$-equivalence is syntactic identity.

View 7 • Self-Reflection

Internalized Metatheory ($\mathcal{T}$ vs. $\mathcal{F}$)

Syntax and derivability are reflected back into View 1 via Gödel coding (#AxmGoedelCodingRoundtrip, $\mathrm{Dec}(\mathrm{Enc}(u)) = u$), internal substitution $\mathrm{SubstVar}(t, x, v)$ (#DefReducedVarSubst), and formal theories $\mathcal{T}, \mathcal{F}, \mathcal{E}$ proving #ThmLoeb and #ThmSecondIncompleteness.

2. Principle 1: Simplify Without Oversimplifying (The Non-Contradiction Boundary)

Sound Unification (Where We Simplify) Essential Decoupling (Where Oversimplifying Causes Contradiction) Paradox Prevented & Kernel Mechanism
0-ary operators unify constants ($\emptyset, V, \mathrm{On}, \omega$) with $n$-ary functional symbols ($\mathcal{P}, \cup, \cap$). Semantic Class (Nonstored.t) $\neq$ Symbol (CpEmptySet) $\neq$ Expression (CEmptySet_Class_Expression). Prevents conflating semantic objects with syntactic variables/substitutions (Fact 1 & Fact 6).
Default variable sort is Class everywhere, including $\{x : \mathrm{Class} \mid \varphi(x)\}$. Membership in $\{x : \mathrm{Class} \mid \varphi(x)\}$ requires $z \in V \land \varphi(z)$ (#RulClassComprehension). Prevents Russell’s Paradox ($R = \{x \mid x \notin x\}$ is a proper class, so $R \notin R$).

First-order sequent calculus operates uniformly on $\Gamma \vdash \varphi$. Metalevel 0 object formulas ($\mathrm{Fm}_0$) $\neq$ Metalevel +1 reflection (TpHolds, FFI, IFV). is_object_level_fm0 guard on PComprAx_prf prevents Tarski’s Undefinability Paradox.
Internalized derivability $(\mathcal{W}, \Gamma \vdash \varphi)$ inside the language. R.E. object theory $\mathcal{T}$ (IpTau) $\neq$ Non-R.E. Henkin completion $\mathcal{F}$ (IpFau) $\neq$ Metatheory $\mathcal{E}$ (IpEau). Respects Gödel’s Incompleteness & Löb’s Theorem (#ThmLoeb, #ThmSecondIncompleteness).
Completeness axioms for the full Henkin theory $\mathcal{F}$ on $\mathrm{Fm}_0$. Semantic Completeness (3.73) $\neq$ Negation-Completeness (3.74). Distinguishes truth-to-derivability bridge from syntactic disjunction of derivability.
