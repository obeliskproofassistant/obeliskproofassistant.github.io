Greetings

This site contains a demonstration of the development of a proof assistant, as well as various related links, texts, presentations, and materials about the foundations of mathematics.

The project aims to achieve three results:

  • a new proof assistant with significantly reduced learning curve and bidirectional communication with mathematical community: it doesn't require a user to learn additional information about term normalisation, foundations, tactics, and many others notions, which are typically unusual for a mathematician to know;
  • a new programming language with certain nice properties(e.g.: better polymorphism) via adding additional abstract layer on compiler of the existing project CakeML;
  • "refactored", but still traditional class-theoretic foundations of mathematics.

Geography of the site visitors

Theory at a Glance: MKTD (Morse–Kelley + Tarski + Dunaev)
Subject MKTD: Morse–Kelley class theory with Tarski’s axiom of universes, using Dunaev pairs as ordered pairs.
Objects Every object is a class. A set is a class that is an element of some class; the other classes are proper classes.
Comprehension For every formula φ(x) there is the class {x | φ(x)} of all sets x with φ(x), also when φ quantifies over classes (as in MK, unlike NBG). Entry 3.01.
Two formal systems MKTD1: a classical sequent calculus, statements of the form (T, Γ ⊢ φ). MKTD2: a classical dependent type theory, statements of the form p : A (propositions as types). Each name comes in three precise forms: -framework, -theory and -system.
Checking Every proof is checked by a small kernel program, one for MKTD1 and one for MKTD2. “Verified” means that the kernel checked a proof of exactly the displayed formula. Other statuses say when a statement is an axiom, an unchecked postulate, or not yet proved.
