# Item 3.53: Axiom of Infinity

$$\mathrm{isSet}(\omega)$$

The $\subseteq$-minimal (least) successor-inductive (Peano-inductive) class $\omega = \bigcap^Q_{\mathrm{Ind}(Q)} Q$ (containing the empty set $\emptyset$ and closed under ordinal successor $x \mapsto x \cup \{x\}$, and therefore minimal in the $\subseteq$ order among all successor-inductive classes as well as the smallest successor-inductive ordinal) is a set. This establishes countable mathematical (Peano) induction, Peano arithmetic, and classical analysis within Obelisk.
