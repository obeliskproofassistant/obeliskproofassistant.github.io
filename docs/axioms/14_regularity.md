# Item 3.14: Regularity via Powerclasses (\in-Induction)

$$\mathcal{P}(X) \subseteq X \implies V \subseteq X$$

### Mathematical Content
Rather than formulating the Foundation / Regularity axiom via minimal elements ($x \cap y = \emptyset$), Obelisk introduces a modern, categorical formulation: $\in$-induction over powerclasses.
If a class $X$ contains every subset of its elements ($\mathcal{P}(X) \subseteq X$), then $X$ necessarily contains the entire universe $V$. This implies that no set can belong to itself, and eliminates infinite descending $\in$-chains.
