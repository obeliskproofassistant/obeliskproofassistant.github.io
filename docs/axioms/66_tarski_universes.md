# Item 3.66: Tarski-Grothendieck Universes

$$\forall X. \mathrm{isSet}(X) \implies \exists U. X \in U \land \mathrm{isUniverse}(U)$$

Every set belongs to an inaccessible Grothendieck universe closed under subsets, pairing, powerclasses, and small unions. This allows large-scale category theory, functor categories, and cohomology theories to be formalized safely.
