# Item 3.13: Exponent / Powerclass Axiom

$$\mathrm{isSet}(X) \implies \mathrm{isSet}(\mathcal{P}(X))$$

### Significance
The collection of all subsets of a set $X$, denoted $\mathcal{P}(X) = \{y \mid y \subseteq X \land \mathrm{isSet}(y)\}$, is itself a set. This establishes Cantor's theorem $|X| \prec |\mathcal{P}(X)|$ and forms the engine of transfinite cardinal hierarchies.
