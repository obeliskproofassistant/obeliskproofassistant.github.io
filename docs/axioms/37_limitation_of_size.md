# Item 3.37: von Neumann Limitation of Size Axiom

$$X \in V \iff |X| \prec |V|$$

### Principle
A class is a set if and only if its cardinality is strictly smaller than the cardinality of the universe $V$. Proper classes are precisely those classes that can be put in bijection with the universal class $V$. This single axiom subsumes both the Axiom of Replacement and the Axiom of Choice.
