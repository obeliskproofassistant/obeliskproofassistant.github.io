Machine-checked specification of classical propositional logic, first-order predicate logic, Morse–Kelley class theory, and type-theoretic side conditions directly generated from Standard ML kernel data structures.

Foundational Semantics & Recursive Side Condition Tower
  • Quantifier Typing Colons: In Morse–Kelley class theory, there is no class of all classes (Russells paradox). Thus, near quantifiers, the colon is traditionally retained (∀(x : Class), ∃(x : Class), ∀(A, B : Class)) to denote variable sorts without falsely implying Class is an element in the object universe.
  • Elementhood: Inside mathematical propositions, elementhood is genuine set/class membership (x ∈ y, x ∈ A, ∅ ∈ x).
  • Side Conditions as Recursive Formulas: Side conditions are not informal remarks—they are genuine formulas at Metalevel 1. A side condition can have side-side conditions at Metalevel 2 (and side-side-side conditions at Metalevel 3). Since one Morse–Kelley theory serves as object theory and metatheory, formulas are stored uniformly as formulas regardless of their metalevel. If a formula is decidable, its decidability is established as a theorem.
