Decoupled Brackets (⟨...⟩ / ⟦...⟧) vs. Special Functional Symbols (Enc, Dec, Emb)
  • Quotation ⟨...⟩ (‹...›) & Antiquotation / Valuation ⟦...⟧ ([|...|]): Purely syntax-splicing and valuation brackets from program/libs/unicodedefs.ML. Inside ⟨...⟩, antiquoting a class variable ⟦X⟧ splices the class X itself—which may be a proper class like V or On! Therefore, isSet(⟦X⟧) is NOT automatically true (e.g. ¬isSet(V) by Russell's theorem).
  • Syntactic Encoding Enc(s) (CpEnc in typetheory.ML): Maps any syntactic object (s : T) (Fm, Stmt, Prf, Ctx, Theory) to its finite Gödel/hereditarily-finite set code in (V_ω ⊂ V). Because every finite syntax tree code is a finite set, isSet(Enc(s)) IS unconditionally true!
  • Syntactic Decoding Dec(c, T) (VDec in typetheory.ML): Partially decodes a set code (c : Class) back into target syntactic collection (T : Col), satisfying the roundtrip law ∀(s : T) (Dec(Enc(s), T) = s).
  • Dual Type Embedding Emb(T) (LTpEmb / TyTpEmb in typetheory.ML): Captures the Dual Semantics of typetheory.ML: (A) Semantic Predicate Interpretation: (Emb(Class)(X) ⟷ ⊤) (so Emb(Class)(V) is a theorem!) and (Emb(Set)(X) ⟷ isSet(X)) (so ¬Emb(Set)(V) is Russell's theorem); (B) Syntactic Code-Class Interpretation: for syntactic types (T ∈ {Fm, Stmt, Prf, Ctx, Theory}), (Emb(T)(x) ⟷ (x ∈ CodeClass(T))), where (CodeClass(T) = { c | (isSet(c) ∧ ∃(s : T) (c = Enc(s))) }).

Reading Guide — Decoding cantor_diagonal_theorem (Dunaev Tagged Pairs & Diagonal Class): In class theory without primitive function application, an indexed family of classes \( \{ F(x) \}_{x \in S} \) is represented by a single class relation \( F \) of Dunaev tagged ordered pairs \( [x, z]_D \) such that \( ([x, z]_D \in F) \longleftrightarrow (z \in F(x)) \). Define Cantor's anti-diagonal class \( D = \{ x \mid ((x \in S) \land (([x, x]_D \in F) \to \bot)) \} \). Then for any index \( x \in S \), if the \( x \)-th fiber \( F(x) \) coincided with \( D \) (i.e. \( \forall z\; ((z \in D) \longleftrightarrow ([x, z]_D \in F)) \)), instantiating \( z := x \) yields the diagonal equivalence \( ((x \in D) \longleftrightarrow ([x, x]_D \in F)) \), which together with \( ((x \in D) \longleftrightarrow ((x \in S) \land \neg([x, x]_D \in F))) \) derives \( \bot \). Thus no class family indexed by \( S \) can surject onto all subclasses of \( S \).
