1) Propositional logic:

1.01) Axm. A01 (Affirmation of Consequent):

           (α → (β → α))
           Side condition: α, β : Bool

1.02) Axm. A02 (Distribution of Implication):

           ((α → (β → γ)) → ((α → β) → (α → γ)))
           Side condition: α, β, γ : Bool

1.03) Axm. A03 (Conjunction Elimination Left):

           ((α ∧ β) → α)
           Side condition: α, β : Bool

1.04) Axm. A04 (Conjunction Elimination Right):

           ((α ∧ β) → β)
           Side condition: α, β : Bool

1.05) Axm. A05 (Conjunction Introduction):

           (α → (β → (α ∧ β)))
           Side condition: α, β : Bool

1.06) Axm. A06 (Disjunction Introduction Left):

           (α → (α ∨ β))
           Side condition: α, β : Bool

1.07) Axm. A07 (Disjunction Introduction Right):

           (β → (α ∨ β))
           Side condition: α, β : Bool

1.08) Axm. A08 (Disjunction Elimination / Cases):

           ((α → γ) → ((β → γ) → ((α ∨ β) → γ)))
           Side condition: α, β, γ : Bool

1.09) Axm. A09 (Negation Introduction / Contradiction):

           ((¬α) → (α → ⊥))
           Side condition: α : Bool

1.10) Axm. A10 (Reductio Ad Absurdum):

           ((α → β) → ((α → ¬β) → ¬α))
           Side condition: α, β : Bool

1.11) Axm. A11 (Ex Falso Quodlibet):

           (⊥ → α)
           Side condition: α : Bool

1.12) Axm. A12 (Law of Excluded Middle):

           (α ∨ ¬α)
           Side condition: α : Bool

1.13) Rule Modus Ponens (MP):

           α, (α → β) ⊢ β
           Side condition: α, β : Bool

2) Predicate logic:

2.01) Axm. Discourse domain is non-empty:

           ∃(K : Class) ⊤
           Side condition: K : Class

2.02) Rule Forall Instantiation (FI):

           (∀(x : Class) φ) → φ[t/x]
           Side condition: FFI(t, v_x, φ)

2.03) Rule Exists Instantiation (EI):

           φ[t/x] → ∃(x : Class) φ
           Side condition: FFI(t, v_x, φ)

2.04) Rule Forall Abstraction (FA / Bernays):

           (ψ → φ) ⊢ (ψ → ∀(x : Class) φ)
           Side condition: NFV(v_x, ψ) ∧ NFV(v_x, Γ)

2.05) Rule Exists Abstraction (EA / Bernays):

           (φ → ψ) ⊢ (∃(x : Class) φ → ψ)
           Side condition: NFV(v_x, ψ) ∧ NFV(v_x, Γ)

2.06) Rule Generalisation (Gen):

           φ ⊢ ∀(x : Class) φ
           Side condition: NFV(v_x, Γ)

3) Set/class-theoretic foundations of mathematics:

3.01) Axm. Class Comprehension Axiom:

           ∀(X : Class) (X ∈ {x | φ(x)} ⟷ (isSet(X) ∧ φ(X)))
           Side condition: NFV(v_C, φ)

3.02) Axm. Extensionality Axiom:

           ∀(A, B : Class) ((∀(x : Class) (x ∈ A ⟷ x ∈ B)) → A = B)
           Side condition: A, B, x : Class

3.08) Axm. Heredity Axiom (Subclasses of Sets are Sets):

           ∀(A, B : Class) ((isSet(B) ∧ A ⊆ B) → isSet(A))
           Side condition: A, B : Class

3.12) Axm. Regularity (Foundation) Axiom:

           ∀(A : Class) (A ≠ ∅ → ∃(x : Class) (x ∈ A ∧ x ∩ A = ∅))
           Side condition: A, x : Class

3.13) Axm. Pairing Axiom:

           ∀(a, b : Class) ((isSet(a) ∧ isSet(b)) → isSet({a, b}))
           Side condition: a, b : Class

3.14) Axm. Union Axiom:

           ∀(A : Class) (isSet(A) → isSet(⋃ A))
           Side condition: A : Class

3.22) Def. IF-THEN-ELSE-FI (Class conditional with NFV side condition and context turnstile):

           W, Γ ⊢ ⟦IF ψ THEN A ELSE B FI⟧ = { v | (ψ ∧ v ∈ A) ∨ (¬ψ ∧ v ∈ B) }
           Side condition: NFV(v_v, ψ) ∧ NFV(v_v, Γ)

3.23) Def. simple_if (polymorphic non-dependent conditional over arbitrary Type):

           simple_if : ∏(α : Type). Bool → α → α → α
           ⟦simple_if α true t1 t2⟧ = ⟦t1⟧,   ⟦simple_if α false t1 t2⟧ = ⟦t2⟧
           Side condition: α : Type, t1, t2 : α

3.24) Def. dependent_if (polymorphic dependent conditional with type computation):

           dependent_if : ∏(T : Bool → Type) (b : Bool). T(true) → T(false) → T(b)
           typeof(⟦if b then t1 else t2⟧) := ⟦simple_if Type b (typeof t1) (typeof t2)⟧
           ⟦if true then t1 else t2⟧ = ⟦t1⟧,   ⟦if false then t1 else t2⟧ = ⟦t2⟧
           Side condition: T : Bool → Type, t1 ∈ T(true), t2 ∈ T(false)

3.32) Thm. Ordinal Induction (∈-Ind):

           (∀(α : Class) (α ∈ On → (∀(β : Class) (β ∈ α → φ(β)) → φ(α))))
           → ∀(α : Class) (α ∈ On → φ(α))
           Side condition: On : Class, WF(∈, On)

3.34) Axm. Power Class Axiom:

           ∀(a : Class) (isSet(a) → isSet(𝒫(a)))
           Side condition: a : Class

3.37) Axm. Replacement / Limitation of Size Axiom:

           ∀(F, A : Class) ((isClassFunction(F) ∧ isSet(A)) → isSet(F[A]))
           Side condition: F, A : Class

3.45) Axm. Infinity Axiom:

           ∃(x : Class) (isSet(x) ∧ ∅ ∈ x ∧ ∀(y : Class) (y ∈ x → y ∪ {y} ∈ x))
           Side condition: x, y : Class

3.46) Axm. Global Choice Axiom:

           ∃(c : Class) (isClassFunction(c) ∧ ∀(x : Class) ((isSet(x) ∧ x ≠ ∅) → c(x) ∈ x))
           Side condition: c, x : Class

3.47) Def. Universal Class (V):

           V = {x | x = x}
           Side condition: V : Class

3.53) Def. Transitive Class Predicate:

           Tr(A) ⟷ ∀(x : Class) (x ∈ A → x ⊆ A)
           Side condition: A, x : Class

3.66) Axm. Tarski's Axiom of Universes:

           ∀(x : Class) (isSet(x) → ∃(u : Class) (isUniverse(u) ∧ x ∈ u ∧ isSet(u)))
           Side condition: x, u : Class

4) Metalogical laws:

4.01) Axm. Instantiation Axiom:

           ∀(A : Type) ∀(G : Ctx) ∀(φ : Fm) ∀(t : eval(A)) ∀(v : Variable) (W, G ⊢ (∀(x : A) φ) → (let v = t in φ))
           Side condition: t : eval(A), v : Variable

4.02) Axm. Generalisation Axiom:

           ∀(A : Type) ∀(Γ : Ctx) ∀(φ : Fm) ∀(v : Variable) (¬(Enc(v) ∈ Ctx.FV(Γ)) → ((W, Γ ⊢ φ) → (W, Γ ⊢ ∀(v : A) φ)))
           Side condition: NFV(v, Γ)

4.03) Rule CoNecessitation:

           (F, [] ⊢ ‹F, Γ ⊢ φ›) ⊢ (F, Γ ⊢ φ)
           Side condition: F ∈ Theory, Γ ∈ Ctx, φ : Fm

4.04) Def. Quantifier Unique (!):

           ∀(φ : Fm) ((!(z : Class) φ) ⟷ ∀(x, y : Class) ((φ[x/z] ∧ φ[y/z]) → x = y))
           Side condition: z, x, y : Variable

4.05) Def. Quantifier Exists and Unique (∃!):

           ∀(φ : Fm) (T, [] ⊢ (∃!(x : Class) φ) ⟷ ((∃(x : Class) φ) ∧ !(x : Class) φ))
           Side condition: x ∈ Variable, φ : Fm

4.06) Axm. Class Comprehension Axiom (Metatheory):

           ∀(φ : Fm) ∀(x : Name) ∀(k : Class.Expr) (FFI(k, x, φ) → (T, [] ⊢ (k ∈ {x | φ}) ⟷ (isSet(k) ∧ φ[k/x])))
           Side condition: FFI(k, x, φ)

5) Tactics and inference rules:

5.01) Thm. Elementary Theorems:

           (F, [B ∈ x] ⊢ ∃(x : Class) (B ∈ x)) ∧ (F, [B ∈ x] ⊢ isSet(B))
           Side condition: B, x : Class

5.02) Rule Definition to Introduction Rule:

           (F, [B ∈ x] ⊢ ∃(x : Class) (B ∈ x)) ⊢ (F, [B ∈ x] ⊢ isSet(B))
           Side condition: B, x : Class

5.03) Rule Deduction Rule Application:

           (F, [] ⊢ (B ∈ x) → isSet(B))
           Side condition: B, x : Class

5.04) Thm. Tactics Proof Example:

           F, [] ⊢ (∃(y : Class) ∀(x : Class) (x ∈ y)) → ∀(x : Class) ∃(y : Class) (x ∈ y)
           Side condition: x, y : Class

6) Incompleteness-related statements:

6.01) Axm. Theories (Metalevel Stratification):

           W ⊆ Q ⊆ T ⊆ F (Tarski hierarchy of theories with Henkin constants)
           Side condition: W, Q, T, F : Theory

6.02) Thm. Löb's Theorem:

           ∀(φ : Fm) (Q, [] ⊢ (T, [] ⊢ (T, [] ⊢ φ) → φ) → (T, [] ⊢ φ))
           Side condition: φ : Fm

6.03) Thm. Gödel's Second Incompleteness Theorem:

           Q, [] ⊢ ¬(T, [] ⊢ ⊥) → ¬(T, [] ⊢ ¬(T, [] ⊢ ⊥))
           Side condition: T, Q : Theory
