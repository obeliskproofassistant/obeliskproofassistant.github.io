Core Objectives

The Obelisk Triad

🏛️

Bidirectional Proof Assistant

Significantly reduces the steep learning curve for working mathematicians. Eliminates opaque tactic noise (intro, apply, rewrite) and normalisation tricks. Every proof step forms an explicit, checkable syntactic tree without hidden reduction steps.

⚙️

Enhanced Language atop CakeML

Constructs a new high-assurance language with full polymorphism (types depending on values) by introducing a clean abstraction and code-generation layer above the verified CakeML compiler.

📐

Refactored Class Foundations

Modernized Morse–Kelley (MK) class-theoretic foundations equipped with Tarski–Grothendieck universes, regularity via powerclasses (∈-induction), and an innovative independent construction of tagged pairs and lists for proper classes.

Compiler Architecture · Standard ML & CakeML

Morse-Kelley Propositions-as-Types: Compiling to Check, Not Execute

In Obelisk, we establish a strict 1-to-1 Curry–Howard correspondence between mathematical theorems of Morse-Kelley (MK) Impredicative Class Theory and compiler types. Because MK allows quantification over proper classes in class comprehension, it provides the full expressive strength of higher-order logic over sets, while the compiler operates under the foundational principle: it compiles not to generate runtime executable bytecode, but strictly to verify whether the proof expression type-checks.

Standard ML Native Kernel

Eliminates dynamically typed languages like Python from the trusted kernel. Fully written in Standard ML 97 targeting the CakeML verified compiler for machine-code assurance down to silicon.

Theorems as Types (1-to-1)

Every mathematical theorem (Modus Ponens, Conjunction Symmetry, Russell Paradox Refutation) corresponds to a unique type. Proof terms are formal witnesses checked by the SML type checker.

Dunaev Tagged Ordered Pairs

Replaces Kuratowski pairs (which inflate rank by +2) with tagged tuples <tag, x, y> that preserve set-theoretic rank, well-foundedness, and algebraic projections without universe elevation.
