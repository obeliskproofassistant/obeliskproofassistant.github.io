Notation Disambiguation & Kernel Contexts (Δ vs Γ) See docs/glossary.md • symbols.html
Context Definitions (Δ vs Γ at first use):
• Context Δ (Variable Signature): Declares object-language variable identifiers and their sorts: Δ = { z : Class, A : Class, B : Class }.
• Context Γ (Proof Hypotheses): Stores local propositional assumptions available for inference: Γ = { hIn : (z ∈ {x | ⊥}) }.
In judgements Δ; Γ ⊢ e : T, Δ types free variables while Γ scopes active proof hypotheses.
Glyph & Keyword Disambiguation:
• ⟦ ⟧ (⟦ ⟧): Antiquotation constructor ⟦e⟧ (ASCII [|e|], constructor EAnti/EEval) embedding evaluated term expressions into formula ASTs; distinguished from external model evaluation &DoubleLeftBracket;φ&DoubleRightBracket;M.
• [ ] (Square Brackets): Relational image f[A] (following relation f) vs Dunaev class-list [X₁, X₂] vs premise judgement list [J₁, J₂] ⊢ φ.
• Set(X) vs isSet(X): Set(X) is the ASCII surface keyword in .nbg syntax; rendered as predicate isSet(X) (∃Y(X ∈ Y)) to prevent confusion with class sort Set.
Glossary of Tagged Class Structures:
• Dunaev Pair (⟨A, B⟩D): Tagged ordered pair (mark(A, 1) ∪ mark(B, 2)) sound for arbitrary proper classes (unlike Kuratowski pairs {{a}, {a, b}} which require a, b ∈ V). Source: foundations.ML (entries 3.76–3.78).
• Dunaev Class-List: Iterated tagged pairing [X₁, ..., X_n] with empty list [] (entry 3.39: DefClassLists) representing class tuples without conglomerates.
