1. The Metatheoretic Perspective: Self-Reflection in Morse–Kelley

🔍 The Secret: The Metatheory is the Same Theory MK

In the Obelisk architecture (cf. program/types/typetheory.ML, program/types/foundations.ML, and Vereshchagin & Shen, Languages and Calculi, Part 2, Ch. 4), the metatheory is not an external, alien formalism: the metatheory is the very same theory Morse–Kelley (MK). There is a class-theoretic (set-theoretic) model of the language of formulas, terms, and variables:

  • Variable Reification (\(x\) vs. \(v_x\)): What was an individual variable \(x\) in the object language becomes an unspecified constant \(v_x \in \mathsf{Variable}\) in the metatheory. We know that distinct variable names yield distinct constants (e.g. \(v_x \ne v_y\)), without needing to fix any arbitrary Gödel numbering or low-level encoding.
  • Side Conditions are Formulas: A side condition is not informal prose. When viewed from the metatheory, what was a "side condition" in the object theory now sits in the "Semantic" column! It is an actual formula \(\mathsf{NFV}(v_x, \phi) \in \mathsf{Bool}\) or \(\mathsf{FFI}(t, v_x, \phi) \in \mathsf{Bool}\) being evaluated on the model of formulas and terms.
  • Formulas vs. Axioms / Theorems: In the metatheory, a side condition is neither an axiom nor a theorem: it is simply a formula that may be true or false depending on the syntactic instances plugged into it. An inference rule fires if and only if this metatheoretic formula evaluates to true.
  • Statement Schemata vs. Theorem Schemata: Do not mix statement schemata and theorem schemata! A statement schema is merely a family of formula types indexed by metavariables. A theorem schema implies that there exists an explicit program (proof term) inhabiting that type for every valid instance.
  • Only One Atomic Type (Class) & Ordinal Induction: The class of ordinal numbers \(\mathrm{On}\) is not a type (it is not syntactic); it is a Class object (\(\mathrm{On} \in \mathsf{Class}\)). In Obelisk, there is only one atomic base object type, called Class, on top of which a dependent type theory is given. Therefore, Ordinal Induction (∈-Ind) is a Theorem Schema over Class with an explicit proof program; the restriction \(\alpha \in \mathrm{On}\) is an internal antecedent in the semantic formula, not a syntactic type.

3. Distinguishing Statement Schemata, Theorem Schemata & Metatheoretic Formulas

📄 Statement Schema (Formula Schema)

A parameterized family of formulas indexed by metavariables (such as formulas \(\phi\) or terms \(t\)). It does not imply the existence of a proof program. It merely specifies a well-formed type in the grammar of the object language.

Example: Impredicative Comprehension schema type ∃ C. ∀ x. (x ∈ C ⇔ isSet(x) ∧ φ(x))
⚡ Theorem Schema (With Constructive Program)

Under the Propositions-as-Types correspondence (Curry–Howard), a theorem schema guarantees that there exists an explicit program (proof term) inhabiting that type for every valid instance.

Example: Ordinal Induction: inhabited by transfinite recursion proof program in Obelisk kernel.
🔬 Metatheoretic Formula (Side Condition)

An ordinary formula within the Morse–Kelley metatheory. It is neither an axiom nor a theorem: it is a computable or checkable predicate that can evaluate to true or false.

Example: FFI(t, vx, φ) evaluates to true iff term t can be substituted for vx without capturing variables.
